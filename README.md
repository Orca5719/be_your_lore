# be_your_lore

世界观一致性检索与判断实验的分支索引。

`main` 只保存导航、实验状态和路线图；每个 benchmark 的可复现实验材料都位于对应的 `benchmark/*` 分支。这样可避免把不同版本的运行时、数据协议和结论混为一谈。

详见 [BENCHMARKS.md](BENCHMARKS.md) 与 [ROADMAP.md](ROADMAP.md)。

## 使用约定

- 冻结分支是历史证据，不改写既有协议、提示、数据或结果。
- 所有结果均保留其原有的标注与审核状态；草案标注或助手审核的结果不等同于独立人工验证的泛化结论。
- 模型权重、虚拟环境、缓存和临时构建物不进入仓库。每个需要 Qwen 的分支都会记录所需模型和运行依赖。
