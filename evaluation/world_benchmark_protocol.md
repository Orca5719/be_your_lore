# 160条世界观 benchmark — 编制规则与分步执行

本轮是扩展测试，固定当前 BGE + Qwen、world-extraction-v4、world-review-v2，先评估当前实现。测试期间不修判断逻辑、不改现有设定、不将测试输入保存为canon。本文件是编制约定，尚不是160条完成或模型成绩。

## 分布（按输入整体标签）

| 组别 | 目标条数 | 预期 |
|---|---:|---|
| 现有证据支持 | 40 | 一致 |
| 现有证据明确不相容 | 80 | 矛盾 |
| 与现有世界有关但证据不足 | 20 | 不确定 |
| 完全无关/其他世界/现实陈述 | 20 | 不确定 |
| 合计 | 160 | |

矛盾输入以时间、人物知识、空间、人物关系、物理规则、世界规则、因果、身份各10条为编制目标；每例指定一个主要维度，也允许多个辅助标签。类型划分是本项目统计约定，不意味着八类互斥。

在上述分布中纳入混合事实输入，不另加总量：计划至少16条“一条支持、一条矛盾”、8条“已知事实+未知信息”；整体状态按矛盾优先，其次不确定，全部支持才一致，同时按每条事实计分，不能仅测总标签。单次输入仍以短中文剧情为主。

## 以当前资料为准

只使用当前四个示例文件的48个片段，全部是测试设定，不代表正式canon。每条保留来源文件、行号、原文和文件内容摘要；标注先于模型运行完成。

- 时间：2063地震、2064安装、章节首次见面/知情/获得与毁坏等；“见过新闻形象”与“首次当面交谈”必须分开。
- 人物知识：父亲未知寄宿、公众未知真名、第三话后德尔塔知情等；某人亲历事件不代表另一个人知道。
- 空间：研究站与终点站位置、广场事件、左右身体位置等；不得凭空补地图、距离或旅行速度。
- 人物关系：明确寄宿、契约、已有物品归属与人物联系；没有亲属、恋爱、敌对记录时只能不确定。
- 物理规则：义肢温度/压力、电池、电容、冷却、夜间太阳能等明确机制；不将现实常识强加新世界。
- 世界规则：契约精神波动、封印双宿主、离体上限、治疗边界等。
- 因果：只判断已明示的条件和后果，例如数据库坏后纸本仍可查、特定力量的记忆代价；同年/同时不证明因果。
- 身份：职业、公众代号/隐藏姓名、寄宿主体等；新身份变化若有不同时间或缺失背景，须审核是否应为不确定。

有歧义的预期先标注争议并修订标注，不能看模型答案后迁就模型。若现有证据不足以支撑某维度的10个独立场景，优先少量明确场景的多种表达并标记共同family，而不增补canon或伪造证据；最终应公开family数及维度覆盖限制。

## 标注与评分

每条有输入、预期整体状态、逐事实原文片段、预期状态、允许的kind、明确证据、标注理由和容易混淆的主体/时间/否定词。逗号前的条件、时间等上下文必须保留，并在后续计分中核对，不只比较事实正文。

无关输入预期不确定，不能将语义检索的强制Top5当作支持，不能因为模型知道外部作品/现实常识就判一致，也不能强制要求检索返回空。

主报告是实际录入端到端：有效预览率、逐事实覆盖、判定/混淆矩阵、结构建议覆盖、证据命中/引用有效性、各维度成绩、成功请求延迟及显存。漏项/校验失败留在分母，失败单列。原因和引用的语义合理性须人工复核，自动来源有效不等于推理正确。判断器诊断报告另列，不取代主成绩。

相同设定的多种措辞属于同一family，公开分组，避免将160条同源变体称作160个独立场景。标注由实现者人工编写，用户可纠正；目前没有独立专家审查，也不是严格独立盲测。
